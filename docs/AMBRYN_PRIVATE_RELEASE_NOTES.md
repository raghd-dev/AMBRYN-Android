# AMBRYN v1.0.0 — Private Portfolio Demo

**Visibility:** Private repository, educational Android demo. **Not a production commerce release.**

## Features and demonstrations

- Kotlin and Jetpack Compose shopping UI; candle catalog, product details, wishlist, cart and demo checkout.
- Admin dashboard with inventory/low-stock signals and improved order status controls.
- Corrected cart duplicate-Compose-key crash and added regression tests.
- Final real emulator screenshot gallery and a short, clearly labeled screenshot slideshow.
- Green automated Android build/test runs, including commit `76bf2f5` before this docs update.

## Important notices

- Demo orders only; no real payments.
- Product images are unchanged and may depict other candle brands. Their redistribution rights have not been cleared. **Keep the project Private.**
- Checkout/Admin gallery screenshots use irreversible overlay redactions for displayed personal fields. Review again before sharing.
- No APK, private credentials, Supabase data, or database backups are included in this release.
- Historical Git/asset review and full live JWT security tests remain release gates for public or production use.
